# Articulated WebXR hands

`left.glb` and `right.glb` are generic-hand assets from the Immersive Web WebXR Input Profiles assets package, the same default model source used by Three.js r180 XRHandMeshModel.

Downloaded from:

- https://cdn.jsdelivr.net/npm/@webxr-input-profiles/assets@1.0/dist/profiles/generic-hand/left.glb
- https://cdn.jsdelivr.net/npm/@webxr-input-profiles/assets@1.0/dist/profiles/generic-hand/right.glb

The MIT license is retained in `LICENSE.md`. The geometry is unmodified. AHAM supplies its own skin shading and drives the 25 named bones from actual WebXR joint positions/orientations. Desktop preview is synthetic and uses the model's bind poses as its anatomical reference. No user hand photographs or biometric models are collected.
